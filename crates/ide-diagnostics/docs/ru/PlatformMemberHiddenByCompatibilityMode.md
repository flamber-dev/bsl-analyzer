# Элемент платформы скрыт режимом совместимости (PlatformMemberHiddenByCompatibilityMode)

## Описание диагностики

Режим совместимости конфигурации (`<CompatibilityMode>` в `Configuration.xml`)
скрывает от кода часть глобального контекста, какой бы новой ни была платформа.
Анализатор сверяет код с каталогом 8.3.27 и режима не учитывает, поэтому
`СтрРазделить` в конфигурации с режимом 8.2.13 проходит без замечаний, а у
заказчика модуль не компилируется: «Процедура или функция с указанным именем не
определена (СтрРазделить)».

Что именно скрывает режим, измерено, а не взято из справки: на 8.3.27.2214 и
8.3.17.1549 перебраны все 604 глобальные функции и свойства на базах, отличающихся
только режимом совместимости (8.2.13, 8.3.1 … 8.3.19, 8.3.27). Ниже порога
скрываются ровно 30 имён (и их английские синонимы); остальное — прочие новые
функции, все типы, методы, `…Асинх` — видно даже в режиме 8.2.13.

| Виден с режима | Имена |
|---|---|
| 8.3.3 | `ХранилищеПользовательскихНастроекДинамическихСписков` (свойство) |
| 8.3.6 | `СтрНайти`, `СтрРазделить`, `СтрСоединить`, `СтрШаблон`, `СтрСравнить`, `СтрНачинаетсяС`, `СтрЗаканчиваетсяНа`, `ПолучитьУникальныйИдентификаторСПоддержкойСовместимости` |
| 8.3.9 | `ПолучитьОтключениеБезопасногоРежима`, `УстановитьОтключениеБезопасногоРежима`, `ПродолжитьВызов`, `ПолучитьКоличествоЗаданийПересчетаИтогов`, `УстановитьКоличествоЗаданийПересчетаИтогов`, `СтрЗаменитьПоРегулярномуВыражению`, `СтрНайтиПоРегулярномуВыражению`, `СтрНайтиВсеПоРегулярномуВыражению`, `СтрПодобнаПоРегулярномуВыражению` |
| 8.3.11 | `ПобитовоеИ`, `ПобитовоеИли`, `ПобитовоеНе`, `ПобитовоеИНе`, `ПобитовоеИсключительноеИли`, `ПобитовыйСдвигВлево`, `ПобитовыйСдвигВправо`, `ПроверитьБит`, `ПроверитьПоБитовойМаске`, `УстановитьБит` |
| 8.3.14 | `КопииБазыДанных` (свойство); свойство `Запрос.ТребуемаяАктуальностьДанных` |
| 8.3.19 | `ХранилищеВнешнихДанныхНавигационныхСсылок` (свойство) |

Глобальное имя ниже порога ломает компиляцию всего модуля. Свойство
`Запрос.ТребуемаяАктуальностьДанных` связывается поздно: модуль компилируется, а
строка падает при выполнении — «Поле объекта не обнаружено».

Режим берётся из настройки проекта `compatibility_mode`, а если она не задана — из
`<CompatibilityMode>` основной конфигурации (см.
`docs/configuration/PROJECT_CONFIGURATION.md`). Он действует на модули конфигурации,
расширений (у расширения своего режима нет — оно работает в режиме расширяемой
конфигурации) и внешних обработок и отчётов проекта: внешняя обработка
компилируется в режиме той базы, в которой её открыли (проверено живьём). Настройка
нужна, когда выгрузка `src` не совпадает с базой заказчика: выгрузка говорит 8.2.13,
а у заказчика 8.3.15 — или наоборот.

## Когда диагностика молчит

- режим неизвестен: нет ни настройки, ни `Configuration.xml` основной конфигурации
  (проект из одного расширения или одних внешних обработок);
- режим `DontUse` (`НеИспользовать`) или значение, которое не является режимом;
- режим не ниже порога имени;
- имя перекрыто методом модуля или экспортом глобального общего модуля — так пишут
  замену функции для старого режима;
- тип значения не выведен как `Запрос`;
- вызов стоит в ветви `#Если`, которую не компилирует ни одно окружение метода, или
  в общем модуле без отмеченных окружений.

Это правило не про версию платформы: функцию, которой нет на старой платформе,
ловит `PlatformMemberNewerThanMinVersion`. Например, `СтрЗаменитьПоРегулярномуВыражению`
в режиме 8.3.17 этим правилом не сообщается (видна с режима 8.3.9), а на платформе
8.3.17 её нет (с 8.3.23).

## Примеры

Режим совместимости конфигурации — 8.2.13.

Неправильно:

```bsl
Процедура Разобрать(Строка)
    Части = СтрРазделить(Строка, ","); // виден с режима 8.3.6
КонецПроцедуры
```

Правильно:

```bsl
Функция РазложитьСтроку(Знач Строка, Разделитель)
    Части = Новый Массив;
    Позиция = Найти(Строка, Разделитель);
    Пока Позиция > 0 Цикл
        Части.Добавить(Лев(Строка, Позиция - 1));
        Строка = Сред(Строка, Позиция + СтрДлина(Разделитель));
        Позиция = Найти(Строка, Разделитель);
    КонецЦикла;
    Части.Добавить(Строка);
    Возврат Части;
КонецФункции
```
