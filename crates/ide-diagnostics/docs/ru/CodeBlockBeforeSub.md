# Определения методов должны размещаться перед операторами тела модуля (CodeBlockBeforeSub)

## Описание диагностики

Стандарт разработки определяет строгий порядок размещения секций в программном модуле:

1. Объявление переменных модуля
2. Определения процедур и функций
3. Операторы тела модуля (инициализация)

Размещение исполняемого кода перед объявлением любой процедуры или функции, в том числе между двумя методами, нарушает установленную структуру модуля. Такой код снижает читаемость и может привести к ошибкам при сопровождении.

## Примеры

### Неправильно

```bsl
Сообщить("Инициализация");
А = 1 + 2;

Процедура ВыполнитьРасчёт()
    // тело процедуры
КонецПроцедуры
```

### Правильно

```bsl
Процедура ВыполнитьРасчёт()
    // тело процедуры
КонецПроцедуры

Сообщить("Инициализация");
А = 1 + 2;
```
