# Неизвестный тип в конструкторе (UnknownTypeInNew)

## Описание диагностики

`Новый <Имя>` называет тип, которого в платформе нет. Это ошибка компиляции, а не
выполнения: платформа отказывается компилировать весь модуль с сообщением «Тип не
определен», поэтому недоступными становятся все процедуры модуля, а не только строка с
опечаткой.

Диагностика срабатывает на форму `Новый <Идентификатор>` (с аргументами и без), когда имя
не является ни платформенным типом (русское и английское написание, регистр не важен), ни
семейством типов, которые платформа отдаёт вне своего списка типов.

## Когда диагностика молчит

- имя типа передано значением: `Новый("Массив")`, `Новый(ИмяТипа)`, `Новый(Тип("..."))` —
  имя известно только на этапе выполнения;
- справка платформы подключена не полностью (справки нет или запрошенный источник
  заменён встроенными данными) либо целевая платформа проекта новее подключённой справки
  или задана, а версию справки определить нельзя: новый релиз может добавлять типы,
  которых в списке нет;
- вызов стоит в ветке `#Если` или в методе под модульным `#Если`, которые не компилирует
  ни одна среда модуля, или в общем модуле без заданных сред;
- имя относится к семейству, которое платформа отдаёт вне списка типов: элементы
  управления формы, расширения управляемой формы, типы XDTO/XML/DOM, описания объектов
  метаданных, наборы записей и ключи записей регистров;
- прежнее имя типа, которое платформа ещё компилирует, а справка знает только новое
  (короткий фиксированный список, сейчас `БлокировкаУстановкиСоединений` — старое имя
  `БлокировкаСеансов`); список не исчерпывающий;
- тип существует, но недоступен в текущей среде исполнения, — это
  `UnavailableInEnvironment`, а не данная диагностика.

## Примеры

Неправильно:

```bsl
Результат = Новый НесуществующийТипОбъекта;
```

Правильно:

```bsl
Результат = Новый Массив;
Результат = Новый("Массив");
```
