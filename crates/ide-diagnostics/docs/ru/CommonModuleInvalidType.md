# Общий модуль недопустимого типа (CommonModuleInvalidType)

## Описание диагностики

Общий модуль должен соответствовать одному из четырех стандартных типов,
определенных правилами разработки. Произвольная комбинация флагов контекста
выполнения затрудняет понимание назначения модуля и может привести к
непредсказуемому поведению при вызове его методов из разных контекстов.

Диагностика проверяет именно сочетание metadata-флагов общего модуля и
срабатывает, если оно не соответствует ни серверному, ни серверному для
вызова с клиента, ни клиентскому, ни клиент-серверному типу.

| Тип общего модуля | Пример наименования | Вызов сервера | Сервер | Внешнее соединение | Клиент (обычное приложение) | Клиент (управляемое приложение) |
| -- | -- | -- | -- | -- | -- | -- |
| Серверный | ОбщегоНазначения (или ОбщегоНазначенияСервер) |   | + | + | + |  |
| Серверный для вызова с клиента | ОбщегоНазначенияВызовСервера | + | + |   |   |  |
| Клиентский | ОбщегоНазначенияКлиент (или ОбщегоНазначенияГлобальный) |   |   |   | + | + |
| Клиент-серверный | ОбщегоНазначенияКлиентСервер |   | + | + | + | + |

Допускаются отступления, взятые из условной формулировки стандарта:

- у клиентского модуля может стоять только один из двух клиентских флагов -
  модуль только для управляемого или только для обычного приложения
  (std469, п. 2.3);
- `Клиент (обычное приложение)` у серверного и клиент-серверного модуля
  требуется, только если конфигурация поддерживает обычное приложение
  (`ordinaryAppSupport`), - так же, как в проверках имён общих модулей;
- `Внешнее соединение` у серверного и клиент-серверного модуля для
  этой проверки типа необязательно: модуль только с флагом `Сервер` —
  обычный серверный модуль рабочей конфигурации (std469, п. 2.1:
  флаги просят «для корректной работы» в соответствующих режимах).
  Отдельной проверки имени серверного шаблона нет. Проверка имени
  клиент-серверного модуля по-прежнему отбирает только шаблон с
  `Внешнее соединение`.

`Глобальный`, `Привилегированный` и `Повторное использование возвращаемых
значений` на результат не влияют. `Вызов сервера` допускается только вместе
с `Сервер` и без других контекстов; любое другое сочетание с `Вызов сервера`
и модуль без единого контекста исполнения - находка.
